# WhatsApp das lojas

**Comece por [`servidor-proprio-wuzapi.md`](servidor-proprio-wuzapi.md).** Desde
25/09/2026 o WhatsApp das lojas roda no servidor próprio (WuzAPI no Google
Cloud), e esse é o manual de operação: onde está, como entrar, onde ficam as
chaves, como ligar uma loja e a manutenção.

A pasta [`historico-w-api/`](historico-w-api/) guarda os documentos da época da
W-API (até 25/09/2026): integração, incidentes e roteiros de configuração.
**São históricos. Não siga as instruções de lá**: a W-API não é mais o provedor,
e a Z-API foi descartada no mesmo dia. Os incidentes continuam úteis como
aprendizado sobre WhatsApp (story, reação, `@lid`, webhook perdido).
